# 时间感 · The 24 Hours of Earth

把地球 46 亿年压缩成 24 小时的滚动叙事：

- 生命出现在 **凌晨 3:54**
- 恐龙灭绝于 **23:39**
- 智人走出非洲是 **23:59:54**
- 你知道的一切文明史——**最后的 0.2 秒**
- 你的 80 年——**0.0015 秒**，比一次快门还短

滚动即穿越：右上角实时走时的地球时钟、顶部进度条、
背景色随地质时代从熔岩红渐变到文明蓝、20 个里程碑事件卡片依次浮现，
结尾落在"你的 0.0015 秒"上。

"宇宙探索系列"第 11 弹 · 第三章「家园」续篇。

## 运行

```bash
npm install --registry=https://registry.npmmirror.com
npm run dev     # → http://localhost:5184
npm test        # 时间映射回归测试（10 项，Node 直接跑）
```

## 数据与校验

- 地质年代与事件：USGS / ICS 国际年代地层表公开值
- 映射：4.54 Ga → 24 h 线性压缩，`yearsAgoToClock()` 纯函数
- 回归测试校准：生命 3:54 ✓ 恐龙灭绝 23:39 ✓ 智人 23:59:54 ✓
  文明 < 1 秒 ✓ 80 年 0.0015 秒 ✓（文案数字与计算严格一致，杜绝"科普文章拍脑袋数字"）

## 架构

单页滚动叙事（deep-sea 同款模式）：数据在 `src/data.js`（事件/背景色/结语），
`App.jsx` 一个 scroll 监听驱动时钟/进度条/背景/卡片淡入，无任何第三方库。
